Diagnostyka Dotacji i Zgodności Regulacyjnej dla MŚP

Jednoplikowe narzędzie HTML (bez zależności zewnętrznych, działa offline) do wstępnego, automatycznego przesiewu potencjału dotacyjnego oraz ryzyk zgodności regulacyjnej (NIS2/uKSC, amortyzacja, fundusze szkoleniowe) dla małych i średnich przedsiębiorstw w Polsce.

Zbudowane jako narzędzie diagnostyczno-leadowe dla działalności doradczej Auraloom Labs / Jakub Wielogórski.

Co robi
Użytkownik wypełnia krótki protokół (§1–§4): sektor, wielkość firmy, plany inwestycyjne, ekspozycja regulacyjna.
Narzędzie generuje wynik: orientacyjny potencjał w PLN, dopasowane programy wsparcia, flagę ryzyka NIS2/uKSC, oraz orientacyjny cennik dalszych usług.
Użytkownik może wysłać wynik mailem (przycisk otwiera gotową wiadomość) lub pobrać go jako PDF (funkcja druku przeglądarki).
Każdy wniosek jest oznaczony etykietą epistemiczną — patrz METODOLOGIA.md.

Szybki start
Lokalnie: 
- pobierz diagnostyka-dotacje-zgodnosc.html i otwórz w dowolnej przeglądarce. Zero instalacji, zero zależności.
  
Ograniczenia
To narzędzie przesiewowe, nie audyt. Nie zastępuje indywidualnej weryfikacji aktualnych naborów, kwalifikowalności kosztów ani klasyfikacji regulacyjnej. Wyniki wymagają potwierdzenia przez doradcę — patrz sekcja "Ograniczenia" w METODOLOGIA.md.
