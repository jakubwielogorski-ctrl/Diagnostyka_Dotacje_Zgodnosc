# Diagnostyka_Dotacje_Zgodnosc
Diagnostyka Dotacji i Zgodności Regulacyjnej dla MŚP Jednoplikowe narzędzie HTML (bez zależności zewnętrznych, działa offline) do wstępnego, automatycznego przesiewu potencjału dotacyjnego oraz ryzyk zgodności regulacyjnej (NIS2/uKSC, amortyzacja, fundusze szkoleniowe) dla małych i średnich przedsiębiorstw w Polsce.
